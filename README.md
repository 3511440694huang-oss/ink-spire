## 简介

《墨塔》是一款面向墨水屏与老旧设备的单机卡牌爬塔游戏。你扮演装订墨塔的匠人，一层层往上翻页：每层选一条路，用牌组解决战斗、事件、商店与营火，直到击败每一幕的首领、翻到最后一页。

整部游戏只有一个 `View`，所有界面、图标、地形、火焰全部由 `Canvas` 手绘；没有一张位图资源，没有动画帧，也没有一行网络代码。为墨水屏做的取舍很直接：**画面只在状态变化时重绘一帧，绝不做过渡与插值**——不拖影、不闪烁、不耗电。

## 玩法

- **四幕，每幕十二层**：战斗、事件、宝箱、商店、营火、精英与首领按固定骨架生成，路线每次不同。
- **回合制卡牌战斗**：每回合 3 点能量、抽 5 张牌；敌人头顶显示本回合意图，先算伤害再决定攻守。
- **牌组构建**：战斗奖励三选一，营火可以休息（回 40% 生命）或升级一张牌，商店可以买牌、遗物、药水、也可以花钱删牌。
- **遗物与药水**：遗物在固定时机自动结算；药水栏基础 3 格，可被遗物继续扩容。
- **三个角色**，三套完全独立的牌池与初始遗物：

  | 角色 | 定位 | 玩法关键词 | 初始生命 |
  | --- | --- | --- | --- |
  | 铁刻 | 墨塔的装订工 | 力量 · 厚盾 · 消耗 | 80 |
  | 游丝 | 缝页的裁线人 | 敏捷 · 虚弱 · 抽牌 | 78 |
  | 灰烬 | 烧掉半本书的人 | 自伤 · 爆发 · 诅咒 | 78 |

- **军师（托管 / 提示）**：战斗右上角「托管」由 AI 逐张替你出牌，随时可停；左下角「提示」只推荐一张并说明理由。二者共用同一套评分。

## 设计要点

### 伤害结算顺序（唯一权威实现）

```
玩家打敌人：(基础伤害 + 力量×倍率 + 遗物加伤)
          → 虚弱 ×0.75 → 易伤 ×1.5 → 笔尖 ×2 → 不低于 0 → 扣格挡
敌人打玩家：(基础伤害 + 敌人力量) → 敌人虚弱 ×0.75 → 玩家易伤 ×1.5 → 扣格挡
```

每一步向下取整。意图估算与实际结算共用同一处计算，保证「看到的数字」就是「打出来的数字」。

### 难度只留一个旋钮

所有敌人都只写「同层次内的相对数值」，实际血量与伤害由 `core/Difficulty` 里两张按幕系数表换算：

```java
HP_PCT  = {80, 72, 65, 58}   // 敌人生命系数
DMG_PCT = {74, 66, 59, 53}   // 敌人伤害系数
```

玩家成长是线性的，所以逐幕系数必须递减，否则后一幕必然变成一堵墙。调平衡只改这两行。

### 军师：影子状态 + 整回合推演

早先的推荐是「一张一张独立打分」，永远学不会顺序——先上易伤还是先打攻击、抽牌该不该先打、能不能凑出斩杀线，这些是一串动作的共同收益。现在的做法：

1. 为每个候选首步复制一份**影子战场**（`CombatState.shadow()` + `EnemyState.copy()`，带 `shadow` 标记，所有写回存档的出口全部跳过）；
2. 在影子上把这一回合真的打完，给出终局价值（伤害、击杀、省下的意图伤害、有效格挡、生命、状态资产）；
3. 谁推演出来的终局最好就打谁。

代价约 0.1 ms/次（最坏 28 ms），换来的是可量化的水平提升：在 201 个真实局面上与穷举搜索的最优解对比，达成率 0.840 → 0.913，明显失误率 8.5% → 2.5%。

### 触摸：视觉不变，判定区外扩

小按钮（牌组、托管、提示、药水……）图标尺寸一点不改，只把判定区外扩一圈。判定顺序是**精确命中优先，点空地时才按「离谁最近」兜底**，所以外扩区域彼此重叠也不会互相抢。

### 存档

`SharedPreferences` 里存一份 JSON（v2），记录角色、关卡进度、牌组、遗物、药水、已看过的事件。只在安全界面（地图、牌组、设置）落盘，战斗中退出不会写坏存档。

## 构建

需要 JDK 17、Android SDK（platform 36、build-tools 35+）与 Gradle 8.x。

```bash
# 1) 指定 SDK 位置
cp local.properties.example local.properties && vi local.properties

# 2) 打包（标准版 / 作弊版）
gradle :app:assembleStandardRelease
gradle :app:assembleCheatRelease
#   产物：app/build/outputs/apk/{standard,cheat}/release/
```

在 **arm64 Android 设备**上离线构建时，官方 aapt2 无法执行，需要本机编译一份并在 `local.properties` 里指定：

```properties
android.aapt2FromMavenOverride=/path/to/aapt2
```

仓库自带的 `build.sh` 是作者在设备上用的快捷脚本，会读取 `JAVA_HOME`、`ANDROID_HOME`、`GRADLE_USER_HOME` 与可选的 `AAPT2_BIN`。

**签名**：仓库不包含签名密钥。把自备的 `keystore/inkspire.keystore` 放进去才会签名（密码可用 `INKSPIRE_STORE_PASSWORD` / `INKSPIRE_KEY_ALIAS` / `INKSPIRE_KEY_PASSWORD` 覆盖）；没有密钥时构建出的是未签名包。

**两个版本**：`standard` 为正常版本；`cheat` 版包名加后缀 `.cheat`，内置一个作弊间（无限能量、无限金币、免费牌等），仅用于本地测试，可与正常版共存。

## 目录结构

```
app/src/main/java/com/inkspire/rogue/
├── MainActivity.java        唯一的 Activity，托管 GameView
├── ui/GameView.java         单文件自绘全部界面（菜单 / 地图 / 战斗 / 商店 / 营火 / 事件 / 牌组…）
├── core/                    规则层
│   ├── CombatEngine.java    全部战斗结算（伤害、状态、遗物钩子、用药水）
│   ├── CombatState.java     战场状态 + 遗物聚合 + 影子副本
│   ├── EnemyState.java      敌人状态、意图、伤害系数换算
│   ├── RunState.java        一局的进度：牌组、遗物、药水、地图、事件去重
│   ├── Difficulty.java      全游戏唯一的难度旋钮
│   ├── MapGenerator.java    四幕 × 十二层的地图生成
│   └── SaveStore.java       存档读写
├── content/                 纯数据：卡池（铁刻 / 游丝 / 灰烬 / 诅咒与状态）、敌人、遗物、事件、药水、商店
├── ai/                      敌人意图（EnemyAi）与军师（TacticalAI：评分 + 推演 + 用药水）
└── model/                   卡牌、效果、状态、遗物、药水、敌人的数据定义
```
